# Ground truth for the TraceDocs sample set

Generated by `samples/generator/ground_truth_doc.py` from the case files. Do not edit by hand; `python samples/validate.py` fails if this file is stale.

All people, documents and amounts are fictional. Items below are *synthetic test edits* and *expected observations*; none of them is a verdict about a person. Boxes everywhere are `[x, y, w, h]`, fractions of the page, origin top-left (contract `Region`); the D1 manifest keeps `bbox` as `[x_min, y_min, x_max, y_max]` next to a contract-shaped `region`.

## How the sets are split

| Split | Variant | Use |
| --- | --- | --- |
| `samples/dev/` | a | Used while building and tuning detectors, rules and thresholds. |
| `samples/test/` | b | Held out. A different variant of every pattern, drawn from disjoint name pools. Never used to tune thresholds; run it once to report results. |

No person, id number, account number, source document or file content appears in both splits (`validate.py` checks all of these).
